Markdown Cheat Sheet
Headings
# Heading 1Largest heading. One per doc usually.
## Heading 2Section title. Most common heading level.
### Heading 3Sub-section title.
#### Heading 4Getting smaller. Good for nested structure.
##### Heading 5Subtle sub-label.
###### Heading 6The whisper. Barely a heading.
Emphasis
**bold text**Strong emphasis. Renders in magenta here.
*italic text*Soft emphasis. Angled, pink tone.
***bold and italic***Both at once. Maximum drama.
~~strikethrough~~Cross something out.
Lists
- item
- item
- itemUnordered bullet list. Also works with * or +
1. first
2. second
3. thirdOrdered / numbered list.
- item
  - nested
  - nestedIndent 2 spaces to nest a sub-list.
Blocks & Dividers
> quoted textBlockquote. Pink left border in this forge.
---Horizontal rule. Draws a divider line.
`inline code`Highlights a word or short snippet inline.
```
code block
```Fenced code block. For multi-line code.
Links & Combos
[Link Text](https://url.com)Clickable hyperlink. Text shown, URL hidden.
## **Bold Header**Combine heading + bold. Cyan header, magenta text inside.
